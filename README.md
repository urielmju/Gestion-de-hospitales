Sistema web para la administración integral de un hospital, desarrollado con ASP.NET MVC, C# y SQL Server

Gestión de pacientes, médicos y personal
Control de citas y expedientes clínicos
Administración de roles y accesos (4 roles diferenciados)
Reportes y consultas mediante vistas y stored procedures
Auditoría de operaciones mediante triggers

Clonar o descargar el repositorio
Restaurar la base de datos usando el script SQL incluido en la carpeta /database
Actualizar la cadena de conexión en Web.config con los datos de tu servidor
Compilar y ejecutar desde Visual Studio
